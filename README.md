🎮 Number Guessing Game

Hey! 👋 Welcome to my Number Guessing Game.
I built this project using Python and Streamlit to practice coding and learn how to turn a simple Python program into a web app.
🚀 Want to Play?
🎯 "Play the game here!" (https://number-guessing-game-dzxto9kp5n7gbf5p5v54mm.streamlit.app/)
I'm thinking of a number between 1 and 100. Can you guess it? The game will tell you if your guess is too high or too low. Keep trying until you get it right!
✨ What can you do?
- Guess a random number between 1 and 100.
- Get hints after every guess.
- Keep track of how many attempts you make.
- Start a new game whenever you win.
💻 Want to Run It on Your Computer?
You can try it locally, too!
1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required package:
   "python -m pip install -r requirements.txt"
5. Run the game:
   "python -m streamlit run app.py"
